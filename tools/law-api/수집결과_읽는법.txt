법제처 Open API 실제 JSON 수집 결과
2026-10-30 / Risk 대응 AI Agent

받은 자료
- 법률·시행령·고시·지침 17개 본문을 실제 인증 API로 받았다.
- 법령 체계도 5건, 위임 관계 10건을 받았다.
- 사용할 목적이 있는 조문 98개와 별표·서식 14개를 따로 골랐다.
- 위임·인용 연결 715개를 정리했다. 이는 의무 715개라는 뜻이 아니다.
- 복수 대상 법령·조문이 한 그룹에 들어와 대응이 불명확한 18개 그룹은 별도로 남겼다.
- 판례·결정례 본문은 0건이다. 이번에는 의무·기한의 법령 원문을 먼저 확보했다.

17개 문서는 무엇에 쓰나
1. 정보통신망법·개인정보 보호법·방송통신발전 기본법·전기통신사업법과 각 시행령: 8개
   최초·추가 신고, 통지, 보고, 갈음, 기한, 내용, 제재의 근거를 확인한다.
2. 고시·지침: 5개
   표준 개인정보 보호지침, 개인정보의 안전성 확보조치 기준,
   주요통신사업자의 통신시설 등급 지정 및 관리 기준,
   과학기술정보통신부 소관 주요정보통신기반시설 보호지침,
   재난 시 무선통신시설 공동이용 범위 및 절차에 대한 고시.
   세부 절차, 신고서, 시설·상황에 따라 달라지는 기준을 확인한다.
3. 정보통신기반 보호법과 시행령: 2개
   지정된 주요정보통신기반시설인 경우의 추가 의무를 검토한다.
4. 민법·행정기본법: 2개
   기간 계산의 일반 규정을 확인한다. 민법 전체를 검색 대상으로 넣지 않고 기간 계산 조문을 따로 골랐다.

화재·산업재해·일반 재난법·상세 제재 및 처분 절차 관련 8개 문서는 확장 후보로 보류했다. 해당 시나리오나 기능이 확정되면 추가한다. collection_policy.json에 이름과 조건이 있다.

API는 어떻게 동작하나
① 문서 이름으로 목록 JSON을 검색한다.
② 목록에서 정확한 이름, 현행 여부, 시행일과 버전을 확인한다.
③ 선택한 버전의 본문 JSON을 받는다. 법령은 MST+efYd, 행정규칙은 일련번호 ID를 사용한다.
④ 하위 규정은 위임 관계 API로 확인한다.
⑤ 연결된 문서를 모두 재귀 수집하지 않고, 서비스 의무·조건을 확인하는 데 필요한 대상만 추가한다.

실제 개인정보 보호법 제34조의 연결 응답에는 시행령 제39조·제39조의2·제39조의3·제40조 등이 구분돼 있다. 출발 조항과 연결 문구도 들어 있다. 법률과 세부 절차를 함께 검색하는 데 쓸 수 있지만, 사고별 적용이나 신고 갈음 판단을 확정하는 데이터는 아니다.

판례는 어떻게 받나
API 권한을 신청했다고 판례를 모두 저장하지 않는다.
먼저 원문만으로 해결되지 않는 구체적인 쟁점을 정한다.
그 쟁점과 관계 법령으로 목록을 조회하고, 사건명·법원·선고일·사건번호를 확인한다.
이유가 있는 후보만 본문을 읽은 뒤, 쟁점·사실관계·적용 법령 시점을 비교해 채택·제외를 기록한다.
작업 시작 한도는 목록 10건, 본문 검토 쟁점당 최대 3건이다. 공식 API 한도가 아니라 무분별한 수집을 막기 위한 기준이다.

파일 용도
- 원본_JSON/: 실제 본문. 본문 내용은 보존하고 상세 링크에 반영된 OC만 가렸다.
- 법령_통합.json: 17개 본문·버전·출처·용도를 하나로 묶었다.
- 가공_JSON/조문_검색후보.jsonl: 98개 조문의 원문, 위치, 버전과 선정 이유.
- 가공_JSON/법령연결.json: 대상이 구별되는 공식 위임·인용 연결.
- 가공_JSON/법령연결_확인필요.json: 대응을 확정하지 않은 관계 그룹.
- 가공_JSON/선정_별표서식.json: 유출 신고서, 관련 제재·시설 기준 등 14개 후보.
- 가공_JSON/전체_별표서식_목록.json: 원문에 포함된 전체 62개 별표·서식 목록과 선별 여부.
- 가공_JSON/수집대상_용도.json: 문서별 활용 기능과 확인할 조문.
- 수집기록/: 실제 목록·본문·관계 응답과 요청 기록.
- 요청예제_수집코드/: 재수집·선별·포장 코드와 요청 예제. 실제 인증값은 없다.

남은 검토
선정 조문은 최종 의무표나 법 적용이 확정된 규칙이 아니다. 여기서 대상·조건·기산점·기한·예외·갈음·제재를 추출하고 검토해야 한다.
부칙과 조문별 시행일도 확인해야 한다. 이번 현행 버전을 과거 사건에 그대로 적용할 수는 없다.
별표·서식 14개 중 13개는 API 본문 텍스트가 있다. 기반시설 대응·복구 고려사항 1개는 링크만 보존했다. HWP/PDF 파일 자체와 실제 신고 창구 안내는 별도 확인 대상이다.
